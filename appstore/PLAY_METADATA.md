## 2. Play Console'da senin yapacakların (web, sırayla)

1. **Uygulama oluştur** — play.google.com/console → *Uygulama oluştur*
   - Uygulama adı: `Ruhnevâz: Namaz Vakti & Kuran` · Varsayılan dil: **Türkçe – tr-TR**
   - Uygulama · **Ücretsiz** · Geliştirici Program Politikaları ve ABD ihracat yasaları kutularını işaretle.
2. **Servis hesabına erişim ver** — *Kullanıcılar ve izinler* → `play-publisher@gen-lang-client-0024734022.iam.gserviceaccount.com` zaten hesapta varsa Ruhnevâz'ı uygulama izinlerine ekle (Yönetici / "Sürümleri yayınla" + "Mağaza girişini yönet"). Böylece kalan her şeyi API ile yaparım.
3. **İlk AAB'yi elle yükle** (Google, paket adını ilk yüklemede bağlar; API ilk yüklemeyi yapamaz):
   *Test → Kapalı test → Alpha (veya yeni kanal) → Yeni sürüm oluştur* → EAS'in ürettiği `.aab` dosyasını sürükle → Play App Signing'i kabul et → Sürüm adı `1.0.0` → *Kaydet* (yayınlamadan).
4. **Test kullanıcıları** — Kapalı test kanalında *Test kullanıcıları* → e-posta listesi oluştur, **en az 12 kişi** ekle (Gmail adresleri). Katılım bağlantısını onlarla paylaş; **14 gün boyunca kesintisiz** kayıtlı kalmaları gerekiyor.
5. Bölüm 3'teki **Uygulama içeriği** formlarını doldur (aşağıdaki cevapları kopyala).
6. Kapalı test sürümünü **incelemeye gönder**.
7. **14 gün sonra** *Kontrol paneli → Üretime erişim başvurusu* (birkaç soru: kaç test kullanıcısı, geri bildirim, neyi düzelttin). Onay gelince üretim sürümü açılır.
